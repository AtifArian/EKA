## 🚀 Run It Now (3 Simple Steps)

### Terminal 1: Backend
```bash
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python create_db.py
python migrate_chat_messaging.py
python run.py
```

### Terminal 2: Frontend
```bash
cd frontend
npm install
npm start
```

### Open Browser
```
http://localhost:3000
```

## 🐛 If Something Goes Wrong

**Backend won't start?**
- Check venv is activated: `venv\Scripts\activate`
- Check .env file exists
- Check port 5000 is free

**Frontend won't load?**
- Check npm installed: `npm --version`
- Check port 3000 is free  
- Check .env file exists

**Chat not working?**
- Both users logged in?
- Request actually sent?
- Check browser console (F12)

**See GETTING_STARTED_CHECKLIST.md for more troubleshooting**
